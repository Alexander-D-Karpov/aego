# Icon catalog

This catalog shows the icon sources available to this documentation build,
including the engine and enabled modules. The names are stable icon IDs used
by editor panels and extensions. Icons use the current interface color, so
they remain readable with light and dark themes.

For a usage and missing-icon audit, run `aego icons list` or `aego icons check`.
