# Команда aego

Каждая команда принимает папку проекта первым аргументом; если его нет, она ищет `project.aego` вверх от текущей папки. Команды выводят диагностику с файлом, строкой и кодом и при любой ошибке завершаются с ненулевым кодом, поэтому в CI они работают без изменений.

## aego new

Создаёт проект из шаблона или примера движка и проверяет его.

| Флаг | Значение |
|---|---|
| `--template empty\|2d\|2.5d\|3d` | начальное содержимое, по умолчанию `2d` |
| `--module name` | путь модуля скриптов, по умолчанию имя папки |
| `--example name` | скопировать пример движка вместо шаблона |
| `--native` | добавить нативный модуль на Go в `native/` |
| `--engine dir` | дерево исходников движка; нужно для нативных проектов и примеров |

## aego edit

Открывает проект в редакторе. Без проекта открывает лаунчер. Нативные проекты работают под присмотром процесса, который пересобирает и перезапускает редактор, когда меняется код на Go.

| Флаг | Значение |
|---|---|
| `--profile name` | профиль настроек игрока для игры в редакторе |
| `--debug` | подробный журнал и отладочный вывод GPU |
| `--cpuprofile file` | записать профиль процессора |
| `--hidden`, `--headless`, `--frames n` | для тестов: скрытое окно, без окна, остановиться через n кадров |

## aego run

Импортирует ассеты и запускает главную сцену. Ассеты и скрипты перезагружаются при сохранении; нативный код пересобирается, и игра перезапускается со своим состоянием.

| Флаг | Значение |
|---|---|
| `--scene file` | запустить эту сцену вместо главной |
| `--profile name` | профиль настроек игрока |
| `--trace file` | при выходе записать трассировку Chrome последних кадров |
| `--headless`, `--frames n` | запустить без окна, остановиться через n кадров |
| `--debug` | подробный журнал и отладочный вывод GPU |

## aego check

Разбирает каждый документ, проверяет файлы `.meta`, разделы проекта и ассеты и проверяет типы в каждом пакете скриптов. Код выхода 1 при проблемах, 2 — когда нативный код не собирается.

Проверка открывает индекс ассетов только для чтения, если не задан `--ensure-meta`; скрипт вне `scripts/` считается ошибкой импорта.

| Флаг | Значение |
|---|---|
| `--explain` | вывести статью справочника для каждого найденного кода диагностики |
| `--ensure-meta` | записать недостающие файлы `.meta`, а не сообщать о них |
| `--manifest file` | проверять по этому манифесту привязок, а не собирать новый |

## aego test

Запускает тесты скриптов `*_test.aes` без окна, а с `--determinism` запускает игру дважды и сравнивает хеши состояния.

| Флаг | Значение |
|---|---|
| `-run name` | только тесты, в имени которых есть эта строка |
| `-v` | перечислить и пройденные тесты; с `--determinism` — службы, которые входят в хеш |
| `-budget n` | бюджет инструкций на тест |
| `-seed n` | зерно `aego/rand`, а с `--determinism` — зерно обоих запусков |
| `--determinism` | сравнить два запуска вместо запуска тестов |
| `--frames n`, `--every n`, `--scene file` | длина запусков, интервал между контрольными точками, сцена для запуска |

## aego export

Собирает игру для распространения, которой не нужны ни Go, ни исходники проекта.

| Флаг | Значение |
|---|---|
| `--target host\|linux\|windows\|darwin` | целевая платформа, по умолчанию `host` |
| `--release`, `--development` | профиль сборки |
| `--out dir` | папка вывода |
| `--check` | только выполнить проверки перед экспортом |
| `--json` | вывести отчёт о сборке в JSON |
| `--cc compiler` | компилятор C для другой платформы |

## aego build

Собирает нативный исполняемый файл проекта с модулем `native/` и выводит путь к нему.

## aego bootstrap

Перегенерирует `.aego/generated` для нативного модуля без сборки.

## aego import

Заново импортирует все ассеты; `--force` не использует кэш артефактов.

## aego icons

`aego icons check` сверяет используемые иконки с исходниками иконок и завершается ошибкой, если иконки нет или она не используется; `aego icons list [--json] [--out file]` выводит манифест.

## aego dump

`aego dump script <package|Type> [--func name]` дизассемблирует скомпилированный пакет скриптов с его строками исходника.

## aego version

`aego version` выводит версию движка и коммит, из которого собрана программа, например `aego 0.11.0-dev (6151233e0586, 2026-10-25T13:17:32Z)`. У сборки из рабочей копии с незакоммиченными изменениями к коммиту добавляется `-dirty`.

## aego mcp

Отдаёт проект по MCP через stdio для таких инструментов, как Claude Code; см. [Работа с ИИ-агентами](ref:agents).

| Флаг | Значение |
|---|---|
| `--watch` | отправлять обновления ресурсов, когда меняются файлы проекта |
| `--interval d` | как часто опрашивает `--watch`, по умолчанию 500ms |
| `--project dir` | папка проекта |

## Правка из командной строки

Эти команды читают и меняют сцены, префабы, ассеты данных и ссылки без редактора. Они используют те же операции, что и редактор, и любое изменение можно отменить, применив обратное ему.

- Пути задаются относительно корня проекта. Узел — это путь от корня (`Player/Sprite`) или `#<id>`. Значение записывается в синтаксисе сцены.
- Каждая команда принимает `--json` (стабильный машиночитаемый отчёт), `--quiet`, `--strict` (предупреждения тоже приводят к ошибке) и `--project dir`.
- Команды, которые пишут, принимают `--dry-run`: он сообщает об изменениях и ничего не трогает.
- Код выхода — 0 при успехе, 1 при ошибке и 2, когда в результате есть проблемы уровня ошибки.
- Пока проект открыт в редакторе, команды, создающие ассеты, отказываются работать. Правки существующих файлов редактор подхватывает.

## aego docs

| Команда | Значение |
|---|---|
| `aego docs export [--out file]` | записать реестр документации в JSON |
| `aego docs check [--strict]` | битые ссылки, пропущенные группы и порядки, привязки без описаний, модули Script API и руководства по скриптам без запускаемого примера |
| `aego docs build [--out dir] [--playground=false] [--repo url]` | собрать статический сайт с песочницей |
| `aego docs serve [--addr host:port]` | собрать, раздать на localhost и пересобирать при изменениях |

`--project dir` документирует собственные скрипты проекта, `--engine dir` указывает на дерево исходников движка.
