# Командная строка и агенты

Всё, что редактор делает с проектом, доступно и через команду `aego`. Поэтому проверки, тесты, сборки и документация работают одинаково на ноутбуке, в CI и для ИИ-агента, который работает над проектом.

## Повседневные команды

| Команда | Что делает |
|---|---|
| `aego new <dir> --template 2d` | создаёт проект из шаблона и проверяет его |
| `aego edit [path]` | открывает проект по пути, редактор на файле сцены или префаба или лаунчер, если проект не найден; `--launcher new` открывает лаунчер |
| `aego run [dir]` | запускает главную сцену и перезагружает ассеты и скрипты при сохранении |
| `aego check [dir]` | компилирует каждый пакет скриптов и проверяет проект; при ошибках в скриптах код выхода 1, при сломанном нативном коде — 2 |
| `aego test [dir]` | запускает тесты скриптов `*_test.aes`; `--determinism` запускает главную сцену дважды и сравнивает хеши состояния |
| `aego export [dir]` | собирает игру для распространения под целевую платформу |
| `aego docs serve` | раздаёт эту документацию вместе с задокументированными скриптами вашего проекта на localhost |

## В CI

`aego check` и `aego test` завершаются с ненулевым кодом при любой ошибке. Они выводят каждую диагностику с файлом, строкой и кодом. Им не нужны ни окно, ни GPU. Типичный конвейер запускает обе команды при каждом push, а перед релизом — `aego export --check`.

## Для агентов

- `aego docs export --out docs.json` записывает весь реестр документации в JSON: руководства, каждую функцию скриптов, компонент, поле и диагностику, а также doc-комментарии ваших собственных скриптов. Дайте агенту этот файл вместо сайта.
- Сайт публикует `llms.txt` — простой список всех страниц с их группой и кратким описанием.
- У диагностик стабильные коды, например `AES2050`. Справочник диагностик объясняет каждую и как её исправить.
