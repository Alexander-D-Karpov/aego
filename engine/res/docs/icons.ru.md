# Каталог иконок

Каталог показывает иконки, доступные текущей сборке документации: иконки
движка и подключённых модулей. Имена — стабильные ID иконок, используемые
панелями и расширениями редактора. Иконки используют текущий цвет интерфейса
и остаются читаемыми в светлой и тёмной темах.

Для проверки использования и отсутствующих иконок выполните `aego icons list`
или `aego icons check`.
