# Форматы файлов

Проект Aego содержит редактируемые исходные файлы; импортёр отдельно готовит артефакты для игры. Большинство собственных текстовых форматов использует синтаксис `aetext`. Для некоторых импортёров должен быть включён соответствующий модуль.

## Проект и исходные файлы

| Файл | Назначение |
|---|---|
| [project.aego](ref:formats/aego) | Идентификатор проекта, начальная сцена и настройки модулей. |
| [.aescene](ref:formats/aescene) | Сцена с узлами, трансформациями и компонентами. |
| [.aeprefab](ref:formats/aeprefab) | Переиспользуемая иерархия и переопределения экземпляров. |
| [.aes](ref:formats/aes) | Исходный код Aego Script. |
| [.aeart](ref:formats/aeart) | Собственный контейнер рисунка Aego, а не файл Aseprite. |
| `.aeanim` | [Клип анимации](ref:formats/aeanim) с дорожками, кадрами и событиями. |
| `.aectrl` | [Контроллер анимации](ref:formats/aectrl) с параметрами, состояниями и переходами. |
| [.aepreset](ref:formats/aepreset) | Сохранённые значения компонента или скрипта. |
| [.aedata](ref:formats/aedata), [.aetable](ref:formats/aetable) | Типизированные записи данных и таблицы. |
| [.aemat](ref:formats/aemat), [.aeshader](ref:formats/aeshader) | Параметры материала и исходный код шейдера. |
| `.glsl` | Подключаемый файл шейдера. |
| [.meta](ref:formats/meta) | Постоянный идентификатор и настройки импорта; храните рядом с исходником. |
| [.aetext](ref:formats/aetext) | Общий структурированный текст; каждый использующий его формат определяет собственную схему. |

## Внешние файлы

| Файл | Что делает импорт |
|---|---|
| `.png` | Импортируется как текстура с отдельными метаданными спрайтов. В [Art Studio](ref:render2d/art) описаны черновик рисунка в памяти и первый Save рабочей версии; само открытие не должно перезаписывать PNG. |
| `.ase`, `.aseprite` | Явный импорт Aseprite создаёт отдельную `.aeart`-копию. Неподдерживаемые данные могут потребовать подтверждения или остановить импорт; оригинал не перезаписывается. |
| `.wav`, `.ogg`, `.mp3` | Звуковые клипы. WAV и Ogg Vorbis поддерживаются напрямую, для преобразования MP3 нужен FFmpeg. См. [Звуковые клипы](ref:audio/clips). |
| `.obj` | Импорт меша при включённом модуле 3D-отрисовки. |

Принимаемое расширение не доказывает наличия полного звукового редактора или редактора 3D-моделей. Реальные возможности создания и редактирования для этой сборки описаны в соответствующем руководстве.

## Сгенерированные файлы и сохранения игры

У [подготовленных артефактов](ref:formats/artifacts), [пакетов примеров .aetry](ref:formats/aetry) и [игровых сохранений .aesave](ref:formats/aesave) разные назначения. Они перечислены в [служебных и runtime-файлах](ref:formats/runtime), а не среди авторских исходников. Кэш импорта, подготовленные бинарные данные и манифесты экспорта нельзя редактировать вместо исходных файлов.
