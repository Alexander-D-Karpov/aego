# Форматы файлов

Проект Aego содержит редактируемые исходные файлы; импортёр отдельно готовит артефакты для игры. Большинство собственных текстовых форматов использует синтаксис `aetext`. Для некоторых импортёров должен быть включён соответствующий модуль.

## Проект и исходные файлы

| Файл | Назначение |
|---|---|
| `project.aego` | Идентификатор проекта, начальная сцена и настройки модулей. См. [Настройки проекта](ref:section/engine). |
| `.aescene` | Сцена с узлами, трансформациями и компонентами. |
| `.aeprefab` | Переиспользуемая иерархия узлов; см. [Префабы](ref:prefabs). |
| `.aes` | Исходный код Aego Script. |
| `.aeart` | Собственный редактируемый контейнер рисунка Aego со слоями и кадрами. Это не файл Aseprite; см. [Пиксельная графика](ref:render2d/art). |
| `.aeanim` | [Клип анимации](ref:formats/aeanim) с дорожками, кадрами и событиями. |
| `.aectrl` | [Контроллер анимации](ref:formats/aectrl) с параметрами, состояниями и переходами. |
| `.aepreset` | Сохранённые значения компонента или скрипта. |
| `.aedata`, `.aetable` | Типизированные файлы данных и таблицы; см. [Данные](ref:data). |
| `.aemat`, `.aeshader` | Параметры материала и исходный код шейдера. |
| `.glsl` | Подключаемый файл шейдера. |
| `.meta` | Сопутствующий файл со стабильным ID ассета и настройками импорта. При переносе или переименовании сохраняйте его рядом с исходником. |

## Внешние файлы

| Файл | Что делает импорт |
|---|---|
| `.png` | Импортируется как текстура; нарезка и настройки хранятся отдельно. Просмотрщик может создать новую редактируемую `.aeart`-копию, не заменяя PNG и не меняя ссылки сцены. |
| `.ase`, `.aseprite` | Явный импорт Aseprite создаёт отдельную `.aeart`-копию. Неподдерживаемые данные могут потребовать подтверждения или остановить импорт; оригинал не перезаписывается. |
| `.wav`, `.ogg`, `.mp3` | Звуковые клипы. WAV и Ogg Vorbis поддерживаются напрямую, для преобразования MP3 нужен FFmpeg. См. [Звуковые клипы](ref:audio/clips). |
| `.obj` | Импорт меша при включённом модуле 3D-отрисовки. |

Импорт аудио и OBJ не означает наличия полноценных редакторов звука и 3D-моделей. Кэш и результаты экспорта создаются автоматически и не заменяют исходники с их файлами `.meta`.
