# Glossary

One term for one thing. The Russian column is filled in during localization; until then it is empty.

| Term | Use for | Not | Russian |
|---|---|---|---|
| project | a folder with project.aego | game folder, workspace | |
| scene | an .aescene file and what it holds | map | |
| node | an object in a scene | entity, game object | |
| component | data and behaviour attached to a node | behaviour, module | |
| script | an .aes file and the type it declares | code file | |
| prefab | an .aeprefab file and its instances | template | |
| instance | a node made from a prefab | copy, clone | |
| asset | a file the project imports | resource | |
| artifact | what importing an asset produces and the game loads | build output | |
| handle | a value a script holds to refer to something the engine owns, such as a sound or a request | pointer, reference | |
| data asset | an .aedata file | config | |
| module | a part of the engine: physics, audio | plugin, package | |
| Play | running the game in the editor | preview | |
| play mode | the state of the editor while Play runs: edits go to a copy | | |
| edit scene | the scene being edited, outside Play | | |
| fixed step | one simulation step at the fixed rate | | |
| tick | the count of fixed steps; a time on the timeline is a tick | | |
| frame | one drawn image | | |
| world | everything one running game holds: its scene, services and modules | | |
| keyframe | a saved copy of the game state for rewinding | snapshot | |
| key | a value at a time in an animation clip | keyframe | |
| clip | an .aeanim file | animation (as a file) | |
| controller | an .aectrl file | state machine (as a file) | |
| signal | a named event a component or script emits | callback | |
| action | a named input such as Jump or Move, bound to keys and buttons | key binding | |
| level | a part of a game the player goes through; it is usually a scene | map, stage | |
| script event | a method the engine calls on scripts, such as OnCollisionEnter | callback, hook | |
| Inspector, Hierarchy, Scene View, Game View | the panels by their titles | | |
