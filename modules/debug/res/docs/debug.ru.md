# Отладочная отрисовка

Линии, стрелки, окружности, прямоугольники, крестики и подписи, нарисованные поверх игры во время игры в редакторе и в `aego run`. Они помогают увидеть, что делает код: путь, конус обзора, скорость.

## Скрипты

    import "aego/debug"

    func Update(dt float) {
      debug.Arrow(node.WorldPosition(), node.WorldPosition() + Velocity * 0.2, Color{0, 1, 0, 1})
      debug.Pen("ai.path", 2)
      debug.Cross(goal, 0.3, Color{1, 0, 1, 1})
    }

По умолчанию примитив живёт один кадр. `debug.Pen(channel, ttl)` задаёт канал и время жизни того, что скрипт нарисует дальше. Положительный ttl считается в секундах игры и стоит на паузе. Отрицательный ttl действует до `debug.Clear`. `PenUnscaled` считает реальные секунды. Однокадровый примитив, нарисованный прямо перед паузой, остаётся видимым, пока игра не продолжится.

## Каналы

Каждый примитив принадлежит каналу. Панель «Отладочная отрисовка» перечисляет каналы запущенной игры и включает и выключает их по одному или набором («Столкновения», «Скорость», «ИИ», «Камера»). Формы физики, контакты, AABB, соединения, острова и дерево широкой фазы — это каналы `physics.*`. По умолчанию они выключены, а включает их меню **Физика**.

## Go

    if d, ok := sdk.Debug(ctx); ok {
      d.Circle(center, 2, &sdk.DebugStyle{Color: sdk.Color{R: 1, A: 1}, Channel: "mygame.spawn", Life: debugdraw.ForSeconds(1)})
    }

`Style.Fade` плавно убирает альфу либо альфу и размер за время жизни. `Thickness` рисует линии толщиной до четырёх пикселей. `Space: Screen` принимает позиции в логических пикселях изображения игры.

## Ограничения

16384 примитива на мир и 4096 на канал; лишние отбрасываются и учитываются в панели. `debug { enabled=false }` в `project.aego` превращает каждый вызов в пустую операцию.
