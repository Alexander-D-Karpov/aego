# Камеры

[Камера 2D](ref:engine.Camera2D) рисует ортогональный вид из 2D-трансформации узла. Рисуют только камеры с включённым полем [«Активен»](ref:engine.Camera2D.Active).

## Масштаб и масштабирование

[«Масштаб»](ref:engine.Camera2D.Zoom) — это число пикселей на единицу мира; по умолчанию 64. Чем больше значение, тем меньшую часть мира видно.

[«Масштабирование»](ref:engine.Camera2D.Scale) решает, как вид следует за размером окна:

| Режим | Поведение |
|---|---|
| free | видимая область растёт вместе с окном |
| pixelPerfect | сохраняет масштабирование [виртуального разрешения](ref:engine.Camera2D.Virtual) в целых пикселях |
| fitVirtual | вписывает [виртуальное разрешение](ref:engine.Camera2D.Virtual) в окно |

## Несколько камер

[«Область вывода»](ref:engine.Camera2D.Viewport) — часть экрана, в которую рисует камера, в нормированных координатах; (0, 0, 1, 1) — весь экран. Камеры рисуют по [«Порядку»](ref:engine.Camera2D.Order), меньший раньше. [«Маска»](ref:engine.Camera2D.Mask) выбирает слои видимости, -1 рисует их все. Камера, которая рисует поверх другой, обычно выключает [«Очистку»](ref:engine.Camera2D.Clear); иначе она сначала заливает свою область вывода [«Цветом очистки»](ref:engine.Camera2D.ClearColor).

## Виртуальные камеры

[Виртуальная камера 2D](ref:camera.VirtualCamera2D) может управлять видом «Камеры 2D»: следить за целью, плавно переходить между планами, трястись и реагировать на зоны. См. [Камеры 2D](ref:camera).
