# Спрайты

[«Отрисовка спрайта»](ref:engine.SpriteRenderer) рисует область текстуры по 2D-трансформации узла. Добавьте его через **Создать → Спрайт** или **Добавить компонент → Отрисовка → Отрисовка спрайта**.

## Размер и опорная точка

[Размер](ref:engine.SpriteRenderer.Size) задаётся в единицах мира. Нулевой размер берёт размер текстуры, делённый на масштаб камеры: текстура 64 пикселя под камерой с масштабом 64 занимает одну единицу в ширину. **Создать → Спрайт** задаёт размер (1, 1).

[Опорная точка](ref:engine.SpriteRenderer.Origin) задаётся в нормализованных координатах спрайта: (0.5, 0.5) — центр и значение по умолчанию, (0, 0) — левый верхний угол. Узел поворачивается и масштабируется вокруг неё.

## Порядок отрисовки

Спрайты сортируются по [Слою](ref:engine.SpriteRenderer.Layer), а внутри слоя — по [Порядку](ref:engine.SpriteRenderer.Order). Спрайты с большими значениями рисуются поверх.

## Цвет и смешивание

[Оттенок](ref:engine.SpriteRenderer.Tint) умножается на текстуру; его альфа задаёт прозрачность. Спрайт без текстуры рисует сплошной прямоугольник цвета оттенка. [Смешивание](ref:engine.SpriteRenderer.Blend) выбирает премультиплицированную альфу, непрозрачное или аддитивное смешивание. [Фильтрация](ref:engine.SpriteRenderer.Filter) выбирает выборку по ближайшему пикселю для пиксель-арта или линейную для гладкой графики.

## Из скриптов

```aes
sr := node.Get<SpriteRenderer>()
if sr != nil {
    sr.Tint = Color{1, 0.4, 0.4, 1}
    sr.FlipX = true
}
```
