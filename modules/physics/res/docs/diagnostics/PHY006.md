---
code: PHY006
severity: warning
title: "A body reparented during Play"
scope: play
---

Moving a node with a Rigid Body 2D under another parent while the game runs recreates the body at the same world position and velocity.

**Fix.** Reparent before Play, or move the body with a joint or a script instead of changing its parent.

## Details

Contacts start over, and joints on the body are rebuilt. This is a warning: the game keeps running.

It appears when the scene is edited during Play, for example by dragging the node in the Hierarchy, so no scene file shows it.
