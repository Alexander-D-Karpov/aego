---
code: PHY005
severity: error
title: "A physics body under a 3D parent"
example: PHY005.aescene
---

Physics 2D works on 2D nodes in a 2D hierarchy.

**Fix.** Move the body out of the 3D branch, or build that part of the scene in 2D.

## Details

A body inside a 3D node has no 2D world transform to simulate, so it is skipped.
