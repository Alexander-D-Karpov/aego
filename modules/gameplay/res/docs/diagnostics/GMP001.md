---
code: GMP001
severity: error
title: "Motion 2D on a body that is not kinematic"
example: GMP001.aescene
---

Motion 2D moves its Rigid Body 2D by casting and setting the position each step, so the body must be kinematic.

**Fix.** Set the Type of Rigid Body 2D to kinematic.

## Details

On a dynamic or static body the physics and the controller fight. This error blocks Play.

Adding Motion 2D does this on its own.
