---
code: GMP001
severity: error
title: "Motion 2D on a body that is not kinematic"
example: GMP001.aescene
---

Motion 2D moves its Body 2D by casting and setting the position each step, so the body must be kinematic. On a dynamic or static body the physics and the controller fight. This error blocks Play.

**Fix.** Set Body 2D Type to kinematic. Adding Motion 2D does this on its own.
