code: ANM009
severity: warning
title: "Root motion has nowhere to go"
scope: play
---

A clip has a root track, a `transform.position` track with `root=true`, but nothing can move the node with it.

**Fix.** Add Motion 2D to the node, set Root Motion to `toTransform`, or play the clip with an Animator.

## Details

An Animator with Root Motion `toMotion` moves its node through Motion 2D, and this node has none; with Root Fallback the node moves its transform instead, without it the motion is dropped. An Animation Player never plays root motion: the root track is off.

It appears during Play, on the first step that has root motion.
