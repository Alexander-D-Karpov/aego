---
code: ANM007
severity: warning
title: "Gameplay content in an unscaled player"
scope: play
---

An Animation Player with Time Domain `unscaled` plays a clip with `authority=simulation` tracks or `gameplay` events. Unscaled players run in real time and are not part of the game state, so those tracks are off and the events arrive as presentation events.

**Fix.** Use Time Domain `game` for animation that changes the game, or make the tracks presentation and the events `presentation`.
