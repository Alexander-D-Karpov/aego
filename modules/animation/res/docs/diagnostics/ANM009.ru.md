---
code: ANM009
title: "Движению корня некуда идти"
---

У клипа есть корневая дорожка — дорожка `transform.position` с `root=true`, — но ничто не может сдвинуть ею узел.

**Как исправить.** Добавьте узлу «Движение 2D», задайте «Движению корня» значение `toTransform` или проигрывайте клип через «Аниматор».

## Подробности

«Аниматор» с «Движением корня» `toMotion` двигает свой узел через «Движение 2D», а у этого узла его нет. С флагом «Корень без Движения 2D» узел вместо этого сдвигает свою трансформацию, без него движение теряется. «Проигрыватель анимации» никогда не воспроизводит движение корня: корневая дорожка у него выключена.

Предупреждение появляется во время игры, на первом шаге с движением корня.
