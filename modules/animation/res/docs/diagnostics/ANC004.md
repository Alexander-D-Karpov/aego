---
code: ANC004
severity: warning
title: "The clip of a state is not loaded"
scope: asset
---

A state names a clip that is not imported, or the clip failed to import. The state still works in the graph, with its transitions and exit times, but it plays nothing: the properties keep the values the last state gave them.

During Play the same code is logged once per state.

**Fix.** Import the clip or pick another one for the state.
