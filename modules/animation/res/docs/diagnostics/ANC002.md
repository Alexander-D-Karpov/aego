---
code: ANC002
severity: error
title: "A state that does not exist"
scope: asset
---

The entry, or the source or target of a transition, names a state the controller does not declare, or the controller has no states. The controller keeps its last good version.

**Fix.** Declare the state with `state "Name" …`, or fix the name; a transition from every state is written `transition "any" to="…"`.
