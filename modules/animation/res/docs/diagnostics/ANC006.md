---
code: ANC006
severity: error
title: "The controller cannot be read"
scope: asset
---

The controller text has something the importer does not know: an unknown block, attribute or field, an attribute written as a field inside the block (or the other way round), or a value of the wrong type. Nothing is ignored silently, so a misspelt setting never vanishes. The message names the line and, for a setting in the wrong place, shows how to write it. The controller keeps its last good version.

**Fix.** Correct the line the message names. The blocks and their settings are listed in [Controllers](ref:animation/controller).
