# Создание объектов и пулы

`scene.Spawn` ставит копию префаба; `scene.Despawn` возвращает её в пул, и следующий `Spawn` того же префаба берёт её снова, а не строит новую.

    @export var Bullet AssetRef<Prefab>

    func Ready() {
      scene.Pool(Bullet, 32)
    }

    func Fire() {
      b := scene.Spawn(Bullet, node.WorldPosition())
    }

| Функция | |
|---|---|
| `scene.Spawn(prefab, pos) NodeRef` | под корнем сцены в 2D-позиции |
| `scene.SpawnAt(prefab, parent, pos, rot) NodeRef` | под родителем с локальной позицией и поворотом |
| `scene.Despawn(node)` | обратно в пул; узел, взятый не из пула, уничтожается |
| `scene.Pool(prefab, n)` | строит `n` копий сразу; их `Ready` выполняется сразу |

# Жизненный цикл

Созданная копия либо новая, либо взята из пула. Обе получают одни и те же события, но копия из пула сохраняет свою структуру, а её значения сбрасываются.

- Новая копия выполняет `Ready`, затем `OnSpawned()`.
- Копия из пула получает значения, которые были у неё при постройке: поля компонентов, позы и флаги включения дочерних узлов, а каждое поле скрипта возвращается к своему значению по умолчанию и значению из префаба. `Ready` снова не выполняется, `OnSpawned()` выполняется.
- `Despawn` выполняет `OnDespawned()`, сразу выключает копию и убирает её в конце кадра: её корутины и подключения к сигналам заканчиваются, её скрипты останавливаются, и она переходит под выключенный узел `Pool`.
- Компоненты и дочерние узлы, добавленные, пока копия была в игре, остаются; пул сбрасывает значения, а не структуру.
- Физическое тело сохраняет свою скорость при повторном создании. Задайте её в `OnSpawned`.
- `Spawn` задаёт позу только 2D-копий; 3D-копии сохраняют позу префаба.
