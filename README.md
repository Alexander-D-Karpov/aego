# Aego — A 2D game engine built in Go.

Build games visually, write gameplay logic in Aego Script, and extend the engine with native Go.

A complete development environment with a visual editor, hot reload, deterministic simulation, frame-by-frame rewind, and cross-platform export. From your first scene to a playable game on Windows, Linux, macOS, and the web.
