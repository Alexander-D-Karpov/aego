Метка анимации

Точка привязки кадра

Координаты в пикселях текущего кадра. Изменяется только точка привязки изображения, коллайдеры не затрагиваются.

Преобразование выделенных пикселей

Оттенки палитры

Сдвинуть цвета выделенных пикселей внутри выбранного диапазона палитры.

Палитра из рисунка

Без квантования рисунок не меняется. Квантование явно ограничивает цвета всей анимации.

Порядок палитры

Укажите все индексы через запятую. Индекс 0 остаётся первым. Перестановка сохраняет вид рисунка.

Перенос / копия ячеек

Смещение от исходных ячеек. Отрицательное число означает предыдущие кадры или нижние слои.
