Aego 0.11: animation, an AI agent in the editor, Russian, and updates that install themselves.

**Animation.** Clips and controllers with an Animation panel and an Animator graph: keyframes for any field, curves, events, sprite flipbooks (Flipbook from Selection), sheet slicing, and controller states with parameters, transitions and blends.

**AI agent.** An Agent panel runs Claude Code inside the editor: every change is a card you apply, an Undo step and a follow-mode view of where it works; a context meter and read budgets keep long sessions in bounds. The agent plays the scene to check its work (`scene_run` with input, asserts and screenshots), attaches scripts to nodes, and draws its own sprites as pixel art or SVG in the project's `art` palette. `aego mcp` and the CLI go through the open editor, so outside agents edit the same scenes.

**Russian.** The editor, the CLI, the documentation and the site in Russian; the language follows the system or the editor preferences.

**Updates.** Installed copies update themselves from signed releases: Aego downloads the new version in the background and installs it when you restart, keeps the previous one for Restore Previous Version, and rolls back a version that stops right after it starts. Help and the launcher choose Auto, Ask or Off and stable or nightly. Exported games can update the same way with `update { url publicKey }` and `aego export --release-json`.

**Editor.** A light theme, smoother play-mode rewind, rewritten documentation with runnable examples, a new landing page and Getting started; new projects go to `AegoProjects`.

**Install.** Linux: `curl -fsSL https://aego.akarpov.ru/install.sh | sh`. Windows: the `-setup.exe` below, or `irm https://aego.akarpov.ru/install.ps1 | iex`. Every file has its SHA-256 sum in `SHA256SUMS.txt`; `release.json` is signed. Copies of 0.10 do not update themselves; install 0.11 once, and later versions arrive by themselves. The macOS `.dmg` is built on a Mac separately and may come later.
