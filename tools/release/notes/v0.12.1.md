Aego 0.12.1 refines the editor and fixes Scene View lighting controls.

**Agent.** Type `@` in the composer to find and mention a scene node or asset. The Design workspace opens the Agent below the Inspector by default; existing saved layouts are preserved. The compact header includes session controls and Follow status.

**Scene View and Inspector.** Turning off scene lighting also exits the surface-normal and shadow debug views. Curve editing, particle controls, icons, menus and tooltips have been improved. Dragging a curve preset through the Inspector supports Undo and Redo.

**Updates and documentation.** Update checks retry supported transient network failures. English and Russian documentation, runnable Try It scenes and icon references have been checked.

**Known performance warning.** The last SwiftShader web-demo measurement before the latest editor changes was 10.0 FPS against a 26–32 FPS target; audio and pump underruns were both zero. This remains a warning, not a passing performance result, and was not remeasured for 0.12.1.

**Windows verification.** A native Windows installer and uninstaller check was not available for this release; Wine is not a substitute for native Windows testing.

**Install.** Windows users can download the installer or portable archive; Linux users can download the AppImage or archive. `SHA256SUMS.txt` lists the checksums, and the update manifest is signed.
