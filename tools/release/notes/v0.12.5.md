Aego 0.12.5 adds Art Workspace authoring, Web Asset Studio and expanded interactive documentation.

**Art Workspace.** Dockable art tools, palette and color controls, layers, an animation timeline and previews share the editor's Art document and history. Existing workspace layouts are preserved. PNG and sprite-sheet workflows retain their source and metadata guards.

**Web Asset Studio.** The browser workspace supports drawing, animation, local file operations, previews and PNG or sprite-sheet export. It uses the shared Art Core; browser file handles are session-only.

**Audio.** Clip documents show waveform navigation, selections, transport controls and source analysis. Web audio can render through a Worker. The edit kernel and volatile history are groundwork: persistent Audio EDL editing and recovery are not complete.

**Documentation and examples.** English and Russian references and guides include runnable Try scenes, search and updated editor guidance. The platformer demo and file interoperability checks have also been updated.

**Formats and safety.** `.aeart` remains the Aego authoring format. Aseprite interchange export is not a lossless canonical Save or a guarantee that all Aseprite features round-trip. Source transactions and recovery require explicit decisions; their file checks are not an atomic compare-and-swap.

**Build candidates.** The separately produced native artifacts are unsigned or ad-hoc signed, macOS artifacts are not notarized, and the update verification key is not injected by the candidate workflow. These candidates are not a published stable update.
