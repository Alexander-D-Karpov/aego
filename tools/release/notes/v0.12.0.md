Aego 0.12 adds materials and shaders, 2D lighting, particles and camera post-processing.

**Materials and shaders.** Create material and shader assets, edit parameters in the Inspector, use per-instance overrides, and preview changes in the editor. Built-in effects include Unlit, Additive, Flash, Dissolve and PixelSnap. Shader and material edits use the editor's history and validation paths.

**2D lighting and surfaces.** Point and spot lights, shadows, normal maps, height-derived normals and emission bring lighting to sprites. The image editor exposes surface channels and a lit preview. The platformer and top-down examples include lighting and material assets.

**Particles.** The CPU particle system supports continuous emitters, bursts, local and world space, presets and reduced-motion policies. The platformer includes dust on movement events, sword sparks, smoke and embers.

**Camera effects.** Compose Bloom, Color Grading, Vignette, Chromatic Aberration, Pixelate, CRT and custom material effects on a camera. Edit effect instances in the Inspector and reuse presets.

**Editor and documentation.** The Agent panel supports Codex as well as Claude Code. The documentation and its runnable Try it scenes cover the rendering features in English and Russian. The browser demo is exported from the platformer project.

**Known checks.** On the tested Linux and Windows Chromium/SwiftShader environments, the web demo's 30 FPS-limit smoke measured below its 26–32 FPS requirement. CI reports this as a warning; the standalone smoke remains strict. Investigation is scheduled for the Stage 13.5 Performance Pass. Hardware-rendered measurements are separate and do not close the issue. Firefox visibility setup can also time out in CI; this is reported as an unverified warning, not a passed hide/resume test.

**Windows verification.** The portable CLI of a test build was checked on native Windows. Installer and uninstaller passed a Wine smoke, but a native Windows installer retest was unavailable at release; Wine is not a substitute for that test.

**Install.** Windows users can download the installer or the portable archive attached to this release. Linux users can download the AppImage or archive. `SHA256SUMS.txt` lists the checksums; the update manifest is signed.
